# GenAI engineering learning portfolio

An index of the twelve labs in the [ProjectPro GenAI Engineer path](https://www.projectpro.io/learning-paths/genai-engineer). Status reflects the course tracker on November 25, 2026; it does not indicate independent implementation or production deployment. Effort is an estimate for an independent build and test, not a historical date or course duration. This repository contains original summaries and references, not course source code or datasets.

| Project | Course status | Estimated build effort | Learning focus |
| --- | --- | --- | --- |
| 1. [NLP text processing and classification](https://www.projectpro.io/project-use-case/nlp-text-processing-classification-python) | Complete | 1 month | Tokenization, n-grams, TF-IDF and text classification. |
| 2. [BERT multiclass text classification](https://www.projectpro.io/project-use-case/multi-class-text-classification-using-bert) | In progress (31%) | 1 month | Compare classical embeddings, recurrent models and BERT. |
| 3. [LLM fundamentals and fine-tuning](https://www.projectpro.io/project-use-case/llm-project-for-beginners-to-build-and-fine-tune-an-llm) | Complete | 1–2 months | Tokenization, prompting, parameter-efficient fine-tuning and evaluation. |
| 4. [LangChain and Streamlit chatbot for EDA](https://www.projectpro.io/project-use-case/streamlit-langchain-chatbot) | Complete | 1 month | Explore SQL and Python generation for exploratory data analysis. |
| 5. [LangChain customer support workflows](https://www.projectpro.io/project-use-case/langchain-project-for-customer-support-app-in-python) | Not started | 1 month | Practice retrieval, ReAct orchestration and speech-to-text. |
| 6. [Text-to-SQL with OpenAI and AWS](https://www.projectpro.io/project-use-case/text-2-sql-llm) | Not started | 2 months | Practice generation, query error handling and an AWS deployment workflow. |
| 7. [Azure ML customer support RAG](https://www.projectpro.io/project-use-case/customer-support-agent-using-azureml-and-openai) | Not started | 2 months | Explore the workflow from embeddings and retrieval to grounded answers and feedback. |
| 8. [Multimodal RAG with Bedrock and FAISS](https://www.projectpro.io/project-use-case/multimodal-rag-recommender-system) | Not started | 2 months | Explore retrieval over text and image-derived descriptions. |
| 9. [Local RAG for metadata generation](https://www.projectpro.io/project-use-case/llama2-project-for-metadata-generation-model) | Not started | 1 month | Explore local Llama 2 inference and FAISS-based retrieval. |
| 10. [Domain fine-tuning with Unsloth and QLoRA](https://www.projectpro.io/project-use-case/medical-ai-chatbot-and-assistant) | Not started | 2 months | Study parameter-efficient adaptation using a medical assistant example; not for clinical use. |
| 11. [AutoGen multi-agent assistant](https://www.projectpro.io/project-use-case/agentic-ai-project-to-build-ai-personal-assistant) | Not started | 2 months | Explore scoped tool integrations and multi-agent coordination. |
| 12. [FastMCP and LangGraph assistant](https://www.projectpro.io/project-use-case/mcp-project-to-build-an-ai-assistant-with-fastmcp) | In progress (0% chapter progress) | 1–2 months | Explore tool discovery and invocation using MCP. |
